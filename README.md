# Personal Website - Chris Chamberlain

This branch contains my website built for production, hosted via GitHub Pages at [chris.chamberlain.id.au](https://chris.chamberlain.id.au). View the source code in the [sources branch](https://github.com/neon64/neon64.github.io/tree/sources)

## Current features

- **online CV** which can be converted to a pretty, functional PDF format just through the browser's native print dialog (currently tested in Chrome and Firefox)
- bit of a meme home page with **self-typing text on a fake terminal emulator** (todo: make it an interactive shell)
- beginnings of a blog (no posts yet)

## Technology stack

Built with Gatsby (+numerous plugins), React, Emotion (CSS in JS) and deployed to GitHub Pages. This means the whole website is written in JavaScript basically. How disgusting.

My next goal is to rewrite the website in either Rust, Haskell or PureScript and have the website be typechecked and verified at compile time.
